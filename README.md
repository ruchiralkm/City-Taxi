# City-Taxi - Taxi Reservation Web Application
As part of a collaborative academic project, I, along with three teammates, developed City-Taxi, a fully functional taxi reservation web application. This project was part of our ASE module and it challenged us to apply a variety of technologies to create a system that provides users with an efficient, secure and reliable way to book taxi services online.
<hr/>
City-Taxi is a taxi reservation app developed for the ASE module. It features real-time driver availability using AJAX, distance calculation via the Haversine formula to match nearby drivers, and secure fare payments through Stripe API. SMS notifications, powered by Infobip, keep passengers and drivers updated. Built with a user-friendly interface using HTML, SCSS, and JavaScript, the backend is managed with PHP and MySQL for smooth operations.
